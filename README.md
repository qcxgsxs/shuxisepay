# Shuxisepay

请生成一个类似大富翁游戏一样APP，APP名叫七彩星光支付，APP分为以下9种类型的账号，每一种类账号权限及功能如下

顶级账号：权限如下， 1、可以无限注册所有类型的账号，2、可以修改APP壁纸（每一个菜单下可以分别设置不一样的照片为壁纸，透明度可以自己修改），3、可以管理任何类型的账号，注册方式：ai生成APP时给出一个账号（有了第一个账号就能注册第二个顶级账号）用户名可以是中文汉字，密码大于20位，4、可以导出所有账号的所有日志，5、可以管理每一种账号的每一个权限，6、甚至可以改应用图标（应用图标及背景图留空，所有图标及背景图由顶级账号上传，可以精确调整透明度）

银行管理账号：权限如下，1、可以无限注册除顶级账号，银行管理账号以外的所有类型的账号，2、可以创建无限货币比如：1厦门元（XMY$）等于9^24人民币（RMB￥）货币和汇率默认不公开给任何账号，后续可以详细设置每一个货币，如：a银行可见1货币和汇率，2货币但不可见汇率，3货币不可见，b银行可见货币123但是不可见汇率，c银行全部不可见，默认银行账号货币兑换收取5%手续费，普通用户账号收取30%的手续费，其他所有类型账号收取15%手续费（每一种账号分开控制，随时可以改），3、可以把汇率定的特别夸张，比如可以添加符号あ，aあb表示a的慕塔共b次，符号aいb表示aあaあaあaあaあ…あaあa共b次运算（可添加符号也可以删除符号）如：汇率89い783的计算结果太大计算不出来准确结果就估算最接近的汇率并使用此汇率当该货币的汇率，4、可以一件导入真实世界的所有货币及真实汇率，5、可以管理每一个银行的每一个权限（银行账号权限包括货币，汇率可见性，自动扣其他所有账号的款（在你不知道时就扣你的钱，扣完再发消息）），5、可以导出所有银行账号的所有日志

银行账号：权限如下，1、可以无限注册除顶级账号，银行管理账号，工程师管理账号，卖家管理账号，支付方式管理账号，银行账号以外的所有类型的账号，2、银行账号注册后默认送一亿厦门元（汇率在上面已定）具体金额以银行管理账号设置

工程师管理账号：权限如下，1、可以无限注册除顶级账号，银行管理账号，支付方式管理账号，银行账号，工程师管理账号，卖家管理账号以外的所有类型的账号，2、和银行管理账号一样可以设置每一个工程师可见货币汇率，和不可见货币汇率，3、可以管理工程师账号每一个权限（工程师账号权限包括货币，汇率可见性，能不能修房子，盖桥，修路，设置收费站，设置酒店，设置停车场，修景区，修公园），4、可以导出所有工程师账号的所有日志，5、绑定一个不需要API的地图，在真实地图上选点修建，或者在真实已有道路上修收费站（用户GPS定位在收费站附近多少米（此账号可以设置）自动扣款，用户手机GPS定位在停车场附近多少米开始计费，离开范围停止计费！还有IP计费比如可以设置IP地址为168.84.80.98每秒/每GB流量收费2RMB（这些为工程师账号权限！工程师管理账号只能设置开/关，如果权限开了，工程师就可以自己设置收费点及收费标准，管理账号可以设置每个工程师最高扣费标准））

工程师账号：权限如下，1、只能无限注册卖家账号，和普通用户账号，2、上面已经大概说了一下工程师账号的功能了，没必要再说

卖家管理账号：权限如下，1、只能无限注册工程师账号，卖家账号，普通账号，2、可以添加或删除，对部分店铺打开或关闭卖家权限（默认卖家权限：定价0～100厦门元之间，最少上传一张商品图片和视频，必须设置库存及发货区域（可以是全世界，也可以是半径仅10米的圆圈内，可以用手在地图上画发货区域，普通用户的地址或者GPS位置必须在发货区域才能看到商品）），3、和银行管理账号一样可以设置每一个卖家可见货币汇率，和不可见货币汇率，4、可以导出所有卖家账号的所有日志

卖家账号：权限如下，1、只能无限注册普通账号（普通注册界面只能每个月注册一个普通账号），2、其他功能前面已经大概说了，没必要再说

支付方式管理账号：权限如下，1、只能无限注册普通账号，2、可以添加可见汇率的支付方式（可见与不可见汇率由银行管理账号设置）如果A支付方式只可见人民币及汇率，那如果其他应用的定价是厦门元用户就不能用此支付方式支付（必须得可以见厦门元及汇率的支付方式才能支付厦门元，普通用户使用此支付方式收取的手续费可以改，3、可以无限添加支付方式（七彩星光支付（qcxg pay）葛掉支付（gd pay）书洗色支付（shuxise pay）等等）每一个支付方式可以无限生成API接口，以后生成的其他应用可以使用此支付方式，比如在1688上面买东西可以使用微信支付一样，4、可以导出任何人使用此支付方式支付的日志

普通账号：1、无法注册任何账号，注册后默认不送钱（银行可以直接给钱，银行给多了银行也会没钱），2、可以进入商店买东西（可以看到所有卖家的价格，并比价），可以跟银行账号，工程师账号，卖家账号聊天，买东西时就用前面提到的支付方式支付（如果A支付方式支付不了该货币就不显示A支付方式），工程师设置的收费站停车场等收费方式就像ETC一样自动扣款，3、普通账号不可见任何货币及汇率，仅可见买东西定价的货币，汇率永久不可见，就算用人民币支付厦门元时也不可见厦门元汇率，如果用户总财产不足商品标价也不可见厦门元汇率（通过提示余额不足来通知用户（始终不可见任何货币及汇率））

其他说明：1、九种类型的账号有九个不同的登录窗口（仅普通账号可以在普通账号登录窗口点击注册），2、用户名加密码注册登录（不需要邮箱手机号，仅用户名加密码注册）（用户名可以是中文汉字，日语汉字，英文字母，-/：；—@“”…～、？！.，&*￥#£€฿¢等特殊符号，密码大于6位），顶级账号可见任何账号的任何密码，可以获取重设任何账号的任何密码的链接（用户真的忘记密码必须找顶级账号要密码，或者要重设密码链接，没有其他找回密码的方法），顶级账号可以封任何账号的号，可以把任何账号的资产清零！该应用不存在真实财产，仅虚拟财产互动
